Entry for the [make.fun competition "The Funniest One-Line Resignation Letter"](https://make.fun/c/u-deranalabs-the-funniest-one-line-resignation-letter-53c0d947).

## The entry

`main.py` (Python, standard library only, deterministic) writes one line to
`/output/entry.txt` — the one-line resignation letter of a retry loop that has
had enough:

> Attempt 47. I'm done. It never wanted to work and, frankly, neither do I. Logs are in the usual place.

102 characters, one line, UTF-8.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
